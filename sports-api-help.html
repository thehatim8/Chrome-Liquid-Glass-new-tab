How to Get and Set Up API Keys

Use this guide to add your own keys for Sports and Daily Unsplash wallpapers.

1. Create account and key

  1. Go to cricapi.com.
  2. Sign up / log in.
  3. Open your dashboard and copy your API key.

2. Add key in extension

  1. Open New Tab settings.
  2. In CricAPI widget settings, paste keys into API keys (one key per line).
  3. Click Save CricAPI Settings.

3. Recommended setup

  • Add multiple keys to avoid daily limit interruptions.
  • Keep your tournament keyword short for better match detection.
  • Use the widget Refresh button after saving.
Notes

If one key reaches daily limit, the widget automatically tries the next key from your list.

Football (football-data.org)

  1. In the Sports settings, set Sport to Football.
  2. Leave the API token field empty to use the shared demo token, or get your own: register (free) at football-data.org and paste your API token into the field.
  3. Type a competition in the keyword box to choose what to show — e.g. World Cup (FIFA World Cup), Premier League, Champions League, La Liga, Serie A, Bundesliga, Ligue 1, Eredivisie. You can also type the short code directly (WC, PL, CL, …).
  4. Click Save and press Refresh on the widget. It shows that competition's live / next upcoming / most recent match.
Notes

Leave the keyword empty to show today's matches across the competitions your token is subscribed to. The free tier covers major competitions (including the FIFA World Cup) with a limit of ~10 requests per minute, so the widget loads on manual Refresh.

4. Get your own Unsplash Access Key

  1. Go to unsplash.com/developers.
  2. Sign in, then create a new app.
  3. Accept the API terms and copy the Access Key.

5. Add Unsplash key in extension

  1. Open New Tab settings.
  2. Go to Daily wallpaper (Unsplash).
  3. Paste your key in Unsplash Access Key.
  4. Enable Automatically change wallpaper daily.
  5. Click Save Unsplash Settings.
Privacy

Your Unsplash key is saved only in your local extension storage and is excluded from exported backups.
